# Cytostorm credits and acknowledgements

This is the running log of everything in Cytostorm that someone else made, and what we owe them for it. Alex started it on 2026-10-08 to do this the right way, even though a commercial release may never happen.

**Rule for every thread:** when you bring in anything you didn't make from scratch (code, art, a font, a sound, a dataset), add a row here in the same change. Give what it is, where it came from, its license, where it's used, and what the license asks of us. Paste the full license text under "License texts" when it requires that. If you can't find a clear license, don't use the thing.

## Third-party material

| What | Source | License | Used in | What we owe |
|---|---|---|---|---|
| Body outline and muscle drawing (front view) | npm package `react-native-body-highlighter` 3.2.0, by ELABBASSI Hicham (2022) | MIT | Campaign body map: `campaign/src/body-art.js` | Ship the copyright notice and license text with the game. It's in the page source now; a native app needs it on a Credits screen. |
| Instrument Sans (font) | Google Fonts | SIL Open Font License 1.1 | Every page's UI text | Nothing while it loads from Google Fonts. If a native app bundles the font files, ship the OFL text with them. |
| IBM Plex Mono (font) | Google Fonts | SIL Open Font License 1.1 | Numbers, labels, timers | Same as Instrument Sans. |

## Made for Cytostorm (nothing owed)

- Game code (prototype/, campaign/, workshop/, tutorial/, deploy/): written in this project.
- Art kit (prototype/assets/): generated by `gen.py` in this project.
- Music and sound (audio/): synthesized from code in this project, with no samples. The Sound Lab page says the same.
